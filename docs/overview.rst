Overview
========

This is a set of tools for working with electronic Flight Journal (eFJ) files.
An eFJ file is a text file that stores personal flight records using `a simple,
intuitive, journal-like, schema </efjdocs/schema.html>`_.

Three interfaces are provided: a primary :ref:`Tk based graphical user
interface<gui>`, providing a one stop shop for working with eFJ files, a
:ref:`command line interface<command_line>` suitable for simple scripting and/or
incorporating eFJ processing functionality into your favorite extensible text
editor, and a :ref:`web interface<webapp>`, which, although more limited than
the other two interfaces, allows the toolkit to be used without needing to
install anything locally.
