* File Menu
** Close without save protection
+ start efjgui, add random text
  - Save is grayed out
+ Select Quit, then No
  - efjgui closes, text not saved
+ start ejfgui, add random text, then Quit, then Yes
  - Save As dialog shown
+ Select cancel
  - efjgui does not close
+ Window close button, then Yes
  - Save As dialog shown
+ Select a file, then Save
  - efjgui closes
  - Selected file contains random text
** Save and Save As management
+ start efjgui, add random text, select "Save As" then Cancel
  - ejfgui does not close
+ Select "Save As", select file, then Save
  - Text is saved to file
+ Add more random text
  - Save is not grayed out
+ Select Save
  - New text saved to file
  - Save grayed out again

* Edit Menu
** Copy, Cut, Paste
+ start efjgui, add random text
+ Copy text with menu
+ Paste copied text with menu
+ Cut text with menu
+ Paste cut text with menu
+ Repeat using keyboard shortcuts
** Goto line
+ Add 3 lines of random text
+ Edit | Goto Line | Cancel
  - Cursor doesn't move
+ CTRL-G | 2 | Return
  - Cursor moves to line 2
+ CTRL-G | 1 | OK
  - Cursor moves to line 1
+ CTRL-G, click on main window
  - Dialog remains above main window
** Search
+ Add random text
+ Edit | Search
  - Search bar displayed
+ Enter search text, then Return
  - Cursor moves forward to start of search text
+ Enter search text, then Next
  - Cursor moves forward to start of search text
+ Enter search text, then Prev
  - Cursor moves backwards to start of search text
+ Close
  - Search bar closes
